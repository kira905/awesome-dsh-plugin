> ### What this is
> **A curated list of DSH plugins**: collected daily from GitHub by searching the `dsh-plugin` topic, then reviewed one by one.
>
> ### What it solves
> Plugin lists rot in two ways: **tag spam** (searchable, but installs into nothing) and **no categories** (a long list of names that tells you nothing about which one fits you). The approach here is machine-collected plus human-reviewed: real plugins sorted by scenario, tag spam removed, with a note on who it is for and how to start.
>
> ### How to use it
> Browse the categorized index in the [README](README.md) and go by scenario (scheduling / panel / memory / sessions / networking …).
>
> ### Getting your plugin listed
> Add the `dsh-plugin` topic and make sure the repo has a README one can actually follow. The next crawl will see it — **inclusion is judged by whether it really works, not by star count**.
